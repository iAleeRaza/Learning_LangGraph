# Learning LangGraph 🦜🕸️

A repository dedicated to mastering Agentic AI workflows using **LangGraph**, **LangChain**, and **Groq**.

## 🚀 Overview
This project contains experiments and notebooks documenting my journey learning LangGraph. It covers everything from basic sequential chains to complex cyclic graphs and state management.

## 🛠️ Tech Stack
- **Framework:** [LangGraph](https://github.com/langchain-ai/langgraph)
- **LLM Provider:** [Groq](https://groq.com/)
- **Environment:** Python 3.13.2
- **Orchestration:** LangChain
